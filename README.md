# Zomato-restaurant-analysis-dashboard
The Zomato Restaurant Analysis Dashboard is a Power BI project that analyzes global restaurant data to provide insights into ratings, cuisines, 
delivery services, and costs, helping support data-driven business decisions.
# short Description
This project focuses on transforming raw restaurant data from multiple Excel files into a clean, interactive, and insightful Power BI dashboard.
The report allows users to explore restaurant statistics worldwide, analyze customer ratings, identify top-performing restaurants, 
and compare costs across countries and cities.
The dashboard supports drill-down analysis, advanced filtering, and interactive visualizations for better decision-making.


 # 🎯 Purpose of the Project
The purpose of this dashboard is to:

Analyze restaurant data globally
Identify highly rated restaurants
Compare restaurant costs across countries and cities
Understand customer preferences and service trends
Provide interactive business insights using Power BI
Enable easy data exploration through filters and navigation

# 📌 Key Insights Generated
Restaurants offering online delivery tend to attract higher customer engagement.
Certain cuisines are significantly more popular across multiple countries.
Some cities have higher average restaurant ratings compared to others.
Average cost for two varies greatly depending on geographical location.
A large number of restaurants fall into mid-level rating categories.
