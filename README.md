# 🍽️ Zomato Restaurant Analysis Dashboard

## 📌 Project Overview
- Developed an interactive Power BI dashboard to analyze global restaurant data.
- Analyzed restaurant performance across multiple countries and cities.
- Provided insights into:
  - Customer ratings
  - Cuisine trends
  - Online delivery services
  - Restaurant costs
- Enabled data-driven business decision-making through interactive visualizations.

---

## 📝 Short Description
- Transformed raw restaurant data from multiple Excel files into a clean and interactive Power BI dashboard.
- Enabled users to:
  - Explore restaurant statistics worldwide
  - Analyze customer ratings
  - Identify top-performing restaurants
  - Compare restaurant costs across locations
- Implemented:
  - Drill-down analysis
  - Advanced filtering
  - Interactive visualizations

---

## 🎯 Purpose of the Project
- Analyze restaurant data globally
- Identify highly rated restaurants
- Compare restaurant costs across countries and cities
- Understand customer preferences and service trends
- Provide business insights using Power BI
- Enable easy data exploration through filters and navigation

---

## 🛠️ Tech Stack Used

| Technology | Purpose |
|------------|---------|
| 📊 Power BI | Data visualization & dashboard development |
| 📑 Microsoft Excel | Data source & preprocessing |
| 🔄 Power Query | Data cleaning & transformation |
| 🧮 DAX (Data Analysis Expressions) | Measures, calculated columns & KPIs |
| 🔗 Data Modeling | Building relationships between tables |

---

## 📂 Data Source
- Multiple Excel files containing restaurant data from different countries and continents.

### Dataset Includes:
- Restaurant Name
- Restaurant Address
- Country
- City
- Cuisine Types
- Aggregate Ratings
- Rating Colors
- Average Cost for Two
- Online Delivery Availability
- Table Booking Availability
- Votes & Customer Reviews

---

## 📈 Dashboard Features

### ✅ Interactive Filters
Users can filter data based on:
- Country
- City
- Rating Color
- Online Delivery Availability
- Table Booking Services

### ✅ Drill-Down Analysis
- Navigate from continent level to country level
- Drill down into cities and restaurants
- Analyze restaurant distribution geographically

### ✅ Responsive Multi-Page Report
- Designed with Zomato-themed UI
- Interactive page navigation
- Mobile-friendly dashboard design

---

## 📌 Key Visualizations Used

| Visualization | Purpose |
|--------------|---------|
| KPI Cards | Restaurant count, average rating & average cost |
| Map Visualization | Global restaurant distribution |
| Gauge Charts | Rating and cost analysis |
| Line/Area Charts | Average ratings analysis |
| Treemap | Rating color distribution |

- Some cities have higher average restaurant ratings.
- Average dining costs vary significantly by location.
